# История изменений

## v1.0.0-rc.1 · 21 ноября 2026

- Первый публичный комплект для одной проверенной Windows-сборки Antigravity 2.33.0.
- Включена последняя редакция перевода с исправленными подписями боковой панели, разделов настроек, выбора модели, стартовых подсказок и навигации.
- Установщик собирает ресурсы локально, проверяет SHA-256 и сохраняет отдельную резервную копию для каждой установки.
- Добавлены русская и английская инструкции, снимки интерфейса и лицензии источников перевода.

The first release candidate packages the existing revised translation for local installation and verified rollback.
